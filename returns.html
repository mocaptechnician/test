Політика конфіденційності

1. Загальні положення

Ця Політика конфіденційності визначає порядок обробки та захисту персональних даних користувачів сайту.

Продавцем та володільцем персональних даних є ФОП «Данилова Альона Олексіївна».

Використовуючи сайт та оформлюючи замовлення, користувач погоджується з цією Політикою конфіденційності.

2. Які дані ми можемо отримувати

Для оформлення та виконання замовлення можуть оброблятися такі дані:

  • ім’я та прізвище покупця;
  • номер телефону;
  • адреса електронної пошти;
  • дані, необхідні для доставки товару;
  • інформація про замовлення;
  • інша інформація, яку покупець добровільно надає під час звернення до продавця.

3. Платіжні дані

Оплата товарів здійснюється через платіжний сервіс WayForPay.

Дані банківської картки, які покупець вводить під час оплати, обробляються платіжним сервісом відповідно до його власних правил та політики конфіденційності.

Продавець не отримує та не зберігає повні дані банківської картки покупця, якщо вони безпосередньо вводяться на стороні платіжного сервісу.

4. Для чого використовуються персональні дані

Персональні дані можуть використовуватися виключно для:

  • оформлення та обробки замовлення;
  • зв’язку з покупцем щодо замовлення;
  • організації доставки товару;
  • здійснення повернення або обміну товару;
  • повернення грошових коштів;
  • виконання вимог законодавства України;
  • розгляду звернень та запитів покупців.

5. Передача даних третім особам

Для виконання замовлення персональні дані можуть передаватися третім особам у випадках, необхідних для надання відповідних послуг.

Зокрема, дані, необхідні для доставки, можуть передаватися службі доставки «Нова пошта».

Платіжні дані обробляються платіжним сервісом WayForPay відповідно до його правил та політики конфіденційності.

Персональні дані не продаються та не передаються третім особам для їхніх власних маркетингових цілей без відповідної правової підстави або згоди користувача.

6. Зберігання персональних даних

Персональні дані зберігаються лише протягом строку, необхідного для виконання цілей, зазначених у цій Політиці, або протягом строку, встановленого законодавством України.

7. Захист персональних даних

Продавець вживає необхідних організаційних і технічних заходів для захисту персональних даних від незаконного доступу, зміни, поширення, втрати або знищення.

8. Права користувача

Користувач має права, передбачені законодавством України у сфері захисту персональних даних, зокрема право отримувати інформацію про обробку своїх персональних даних, вимагати виправлення неточних даних та в передбачених законом випадках вимагати їх видалення або припинення обробки.

Для реалізації своїх прав або з питань обробки персональних даних користувач може звернутися до продавця за контактними даними, зазначеними нижче.
